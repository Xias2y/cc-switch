# Krill 发布说明约定 / Release note conventions

## 中文

- 本分支的 GitHub Release 标题与说明只使用中文和英文，中文在前，英文在后。
- 仅首个发布版本保留 Krill / Superba 致谢与账号提及，后续发布不重复致谢或 @。
- 仓库中的版本说明与 GitHub Release 正文保持一致，保留各版本的真实行为与验证范围。
- 只修改已发布版本的说明时，编辑 Release 正文即可，无需重新编译、上传附件或移动标签。

## English

- Use only Chinese and English in this fork's GitHub Release titles and descriptions,
  with Chinese first and English second.
- Keep the Krill / Superba acknowledgement and account mention in the first release only.
  Do not repeat acknowledgements or mentions in later releases.
- Keep repository notes aligned with GitHub descriptions and preserve each version's
  actual behavior and validation scope.
- Edit release descriptions directly for documentation-only corrections; no rebuild,
  asset upload or tag change is needed.
