# CC Switch For Krill 0.1.2

## 中文

1. **保留升级安装目录**：从原版 MSI 迁移到本分支的 EXE 安装包时，先读取旧安装的目录，再卸载旧程序，避免自动改装到用户目录。兼容当前用户和计算机范围的 MSI 登记；已有 NSIS 安装继续沿用其登记目录，手动选择的目录优先。
2. **补齐任务栏图标初始化**：Windows 主窗口同时提供原有小图标和任务栏大图标，避免大图标缺失时显示系统通用窗口图标。安装器也使用 CCS 原图标。
3. **保留现有功能**：沿用 0.1.1 的官方／Krill 聚合 WS、原生压缩、zstd 和被动 WS 标签。本版不新增探测请求。

应用、安装包和更新器版本统一为 `0.1.2`。安装目录修复不会自动移动此前已迁移的安装；需要改回其他目录时，可退出应用后运行安装器选择目录，保留原配置。

## English

1. **Preserve the installation directory during migration**: read the old MSI installation directory before uninstalling it when moving to this fork's EXE installer. Support both per-user and machine-wide MSI registrations. Existing NSIS registration and an explicitly selected directory retain precedence.
2. **Initialize the taskbar icon explicitly**: the Windows main window supplies both its existing small icon and a large taskbar icon, avoiding the generic window icon when the latter is missing. The installer also uses the original CCS icon.
3. **Retain existing functionality**: official/Krill aggregation WS, native compaction, zstd and passive WS status from 0.1.1 remain available. This release adds no probe requests.

The application, installer and updater all use `0.1.2`. The migration fix does not automatically relocate an installation that already moved. To choose another directory, exit the app and run the installer while keeping the existing configuration.
