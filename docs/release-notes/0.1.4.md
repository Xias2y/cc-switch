# CC Switch For Krill 0.1.4

## 中文

1. **恢复 Krill 速度选项**：修复路由／聚合模式生成第三方模型目录时清空速度档位的问题。按 Krill 原生目录和精确模型名保留 Fast、Ultrafast 能力。
2. **按来源缓存能力**：模型能力按端点、凭据指纹和目录协议版本隔离缓存，六小时后在准备路由／聚合配置时刷新；不保存 API Key，也不向其他供应商或未知别名套用速度档位。
3. **保留客户端选择**：HTTP 和 WebSocket 转发保留请求中的 `service_tier`，不强制覆盖每次请求。

验证：125 项 Rust 目录／转发回归、12 项版本相关前端测试、TypeScript、前端构建、Rust 格式检查、Clippy 和 Windows x64 发布构建通过。CI 中 3 项需要私有凭据的实时测试默认忽略；另外执行了 10 项隔离的 Krill 实际请求测试。

**实际请求限制**：Astra、Sol、Terra 的 HTTP Fast 均返回 `priority`，3 项通过。Astra/Sol 的 Ultrafast 请求完成后返回 `default`，未通过实际档位验收；WebSocket 直接上游握手返回 `426`。绕过 CCS 比较原生接口、三条公开线路及 `-ultrafast` 模型名，仍未获得 `ultrafast` 完成响应。此版本恢复上游声明的速度选项，不承诺当前账号／线路的 Ultrafast 已实际生效。完整脱敏记录随附件提供。

使用方式：下载安装包，或解压便携版。重新应用路由／聚合配置后重启 Codex，读取新的模型目录；先前手动添加过 `service_tier` Body 覆盖的用户需移除该覆盖，才能由客户端选择档位。

本次提供 Windows x64 安装包、便携包、实测报告、自动更新签名、更新清单及 SHA-256 校验值。现已使用与 0.1.3 内置公钥匹配的原密钥补齐签名，0.1.4 已设为 Latest，可从 CCS 应用内检查更新并升级；也可手动下载安装。安装包保持原发布产物不变，补齐更新附件未安装或替换本机正在使用的 CCS。

构建源码为 `584a8fb`，之后的提交仅补充验收报告和发布说明。构建记录：https://github.com/Xias2y/cc-switch/actions/runs/42956935551

## English

1. **Restore Krill speed choices**: preserve the native catalog's Fast and Ultrafast capabilities for exact matching models when generating routing/aggregation catalogs.
2. **Scope capability caches**: cache model metadata for six hours per endpoint, credential fingerprint and catalog protocol version. API keys are not stored; unrelated providers and unknown aliases do not inherit these tiers.
3. **Preserve client selections**: HTTP and WebSocket forwarding retain the requested `service_tier` without forcing a provider-wide override.

Validation passed: 125 Rust catalog/forwarding regressions, 12 frontend version tests, TypeScript, frontend build, Rust formatting, Clippy and the Windows x64 release build. Three credential-dependent live tests were ignored in CI; ten additional isolated requests were tested against Krill.

**Live limitations**: HTTP Fast returned `priority` for Astra, Sol and Terra, passing three cases. Astra/Sol Ultrafast completed with `default`, failing the requested-tier assertion; direct upstream WebSocket handshakes returned 426. Direct native-endpoint, three public-line and suffix-name controls also did not produce an `ultrafast` completed response. This release restores advertised model capabilities; it does not claim operational Ultrafast for the tested credentials or routes. The sanitized report is attached.

Install the setup package or extract the portable package, reapply routing/aggregation configuration and restart Codex to reload its model catalog. Remove an existing manual `service_tier` Body override to let the client select the tier.

Assets include the Windows x64 installer, portable archive, sanitized live report, updater signature, update manifest and SHA-256 checksums. The original key matching the public key embedded in 0.1.3 now signs this release. Version 0.1.4 is marked Latest and can be installed through the CCS in-app updater or downloaded manually. The original installer is unchanged; adding updater assets did not replace the active local installation.
