# CC Switch For Krill 0.0.2

## 中文

在上一版官方账号与 Krill 原生 WS、上下文压缩及 HTTP zstd 后端的基础上，
为 Codex 聚合模式新增可用性标志。

### 更新内容

- 在现有默认、官方、模型数量标签旁增加 **WS / CMP**，沿用 CCS 原版标签样式。
- 绿色表示该供应商最近使用的 GPT 模型已确认可用；灰色表示不可用、未确认或证据过期，
  悬停可查看对应模型与原因。
- WS 观察正常连接和响应。本版 CMP 使用实际原生压缩结果，也会在模型使用时发起小型独立探测；
  成功后缓存 24 小时，临时失败至少等待 15 分钟并在后续模型使用时重试。
- UI 刷新只读取本地证据。CMP 独立探测可能消耗少量额度，不发送用户对话历史或工具。
- 保留原有后端路由、账号与 API Key 隔离及 HTTP 回退。

### 范围与验证

本版在本地编译为 Windows x64 安装程序，并生成本分支的更新器签名，非 Windows
Authenticode 签名。UI 通过 Rust 静态检查、格式检查、TypeScript 检查及前端构建，
未新增实际模型验收。此前后端测试见上一版说明。

Krill 仍使用配置的单一端点，未加入三线路自动选择。原生压缩密文不保证可跨供应商或账号使用。

## English

This release adds availability badges to Codex aggregation, building on the native
official-account/Krill WS, context compaction and HTTP zstd backend.

### Changes

- Add **WS / CMP** beside the existing default, official and model-count chips using the
  original CC Switch chip design.
- Green means recently verified for the provider's most recently used GPT model. Gray means
  unavailable, unverified or expired; hover for the model and reason.
- WS observes normal connections and responses. In this version, CMP uses real compaction
  results or a small isolated probe on model use. Success is cached for 24 hours; temporary
  failures wait at least 15 minutes and require further model use before retrying.
- UI reads only local evidence. The CMP probe can consume a small amount of quota and sends
  no conversation history or tools.
- Preserve existing backend routing, account/key isolation and HTTP fallback.

### Scope and validation

Built locally for Windows x64 with this fork's updater signatures, not Windows Authenticode.
The UI passed static Rust lint/format and TypeScript checks and a renderer build. No new live
model acceptance run is claimed; earlier backend tests are documented in the previous release.

Krill still uses its configured endpoint without three-line automatic selection. Native
compaction ciphertext is not guaranteed portable across accounts or providers.
