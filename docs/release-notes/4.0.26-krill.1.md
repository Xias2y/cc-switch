# CC Switch 4.0.26-krill.1

This is a Krill-focused fork based on upstream CC Switch v4.0.25, published by
Xias2y. It is not an upstream CC Switch release.

## Changes

- Native Codex Responses WebSockets for official accounts and Krill in aggregation mode.
- Preserve Krill's native context compaction and replay, with explicit source/account checks.
- Automatic HTTP zstd request compression and HTTP fallback when WS cannot be used.
- Keep CC Switch's existing model selection, OAuth/API-key isolation, usage logging,
  summary compatibility and routing failover behavior.
- Use this fork's own updater endpoint and signing key.

## Scope

The previously requested availability badges are not included in this backend
release. Krill uses the single endpoint configured on its provider card; this
release does not add Superba's three-line automatic selection. Native compaction
ciphertext is not guaranteed to be readable across providers or accounts.

Prior backend testing includes 4,348 library tests and 109 integration tests, as
well as live official/Krill model checks. Subsequent static-review corrections
passed Clippy and formatting checks; those corrections were not followed by a
new live acceptance run. This release is compiled locally for Windows x86_64.
