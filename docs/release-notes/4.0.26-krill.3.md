# CC Switch 4.0.26-krill.3

This release removes the automatic CMP capability probe introduced in
4.0.26-krill.2. Both **WS** and **CMP** now derive their evidence solely from
normal routed traffic and local configuration. Badge polling and cache expiry
never send extra model requests or consume additional tokens.

- WS observes normal handshakes and responses.
- CMP observes real native compaction results. Until one is observed, gray means
  unverified and does not mean the provider lacks support.
- Keep the existing chip design, account/provider isolation and backend routing.
- Normal model use and context compaction still incur their usual upstream usage.

This is an independent Krill-focused fork based on upstream CC Switch v4.0.25.
Thank you to **[@krill-lab/Superba](https://github.com/krill-lab/superba)** for the
reference implementation and to upstream CC Switch contributors.

Validation: static checks and a Windows x64 release build. No new live model
acceptance run or generated capability-check request is part of this release.
