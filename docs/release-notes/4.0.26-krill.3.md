# CC Switch 4.0.26-krill.3

## 中文

移除 4.0.26-krill.2 引入的 CMP 主动探测。**WS / CMP 仅从正常请求和本地配置读取状态，
不为标签额外发送模型请求，不额外消耗 token。**

- WS 观察正常连接的握手与响应。
- CMP 观察正常会话实际产生的原生压缩结果。尚未观察到时，灰色表示未确认。
- UI 刷新、缓存过期均不触发主动探测。
- 保留 CCS 原版标签样式、账号与供应商隔离及后端路由。
- 正常对话和实际上下文压缩仍按上游规则产生用量。

本分支专门支持 Krill，基于上游 CC Switch v4.0.25 独立维护。本版通过静态检查及
Windows x64 发布构建，未新增实际模型验收或生成式探测请求。

## English

This release removes the automatic CMP probe introduced in 4.0.26-krill.2.
**WS / CMP derive their evidence only from normal traffic and local configuration,
with no additional model requests or tokens consumed for badge detection.**

- WS observes normal handshakes and responses.
- CMP observes real native compaction results. Until one is observed, gray means unverified.
- UI polling and cache expiry never trigger active probes.
- Keep the original chip design, account/provider isolation and backend routing.
- Normal conversation and actual context compaction retain their usual upstream usage.

This independent Krill-focused fork is based on upstream CC Switch v4.0.25. Validation
includes static checks and a Windows x64 release build. No new live model acceptance run
or generated capability-check request is part of this release.
