# CC Switch For Krill 0.1.3

## 中文

1. **默认严格原生透传**：官方与 Krill 原生 GPT 路径同时覆盖 HTTP 和 WS；保留推理、原生压缩、消息、工具调用／结果、ID 和密文，不再通过自动删项恢复来掩盖不兼容。
2. **如实保留失败**：目标拒绝加密状态时返回原始上游错误，保留历史；不会替换成占位压缩说明，也不做摘要恢复。
3. **减少切换引发的额外压缩**：Krill 与当前官方同名模型的原生压缩标记及工具／子代理协议一致时保留标记，避免仅因换线路先压缩。其他模型继续使用原 CCS 分组。
4. **保护结构化历史**：保留嵌套工具数据，拒绝改写上下文的请求覆盖配置；严格路径也保持原生响应事件，不自动补写工具参数。
5. **保留传输能力**：继续支持 WS 预热、增量续接、HTTP 回退、zstd、认证隔离及被动 WS 标签；其他供应商的协议转换和兼容修复保持原路径。

严格透传不等于保证任意渠道互读。官方到 Krill 已有原样成功样本；Krill 产生的原生状态切到官方仍可能被拒绝。本版选择报错并保留历史，不能保证任意双向无损切换。应用、安装包、更新器版本统一为 `0.1.3`。

验证：4363 项 Rust 回归、68 项供应商／代理集成测试、TypeScript 类型检查、Clippy 与更新摘要检查通过。实际官方／Krill `gpt-6.1-sol` 覆盖预热、增量上下文、工具、压缩、推理和跨渠道拒绝。13 项原有忽略测试及 2 项 Windows 符号链接权限测试不计入通过数量。

## English

1. **Strict native passthrough by default** for official/Krill GPT over HTTP and WS, preserving reasoning, compaction, messages, tool calls/results, IDs and ciphertext without lossy repair retries.
2. **Preserve genuine failures**: return upstream encrypted-state errors with history intact; no compaction placeholders or summary recovery.
3. **Avoid unnecessary switch compaction** when the same official/Krill model shares its native marker, tool mode and sub-agent protocol. Other models retain CCS grouping.
4. **Protect structured context**: retain nested tool data, reject context-changing overrides and preserve native response events without late-argument rewriting.
5. **Retain transport features**: WS prewarming, incremental continuation, HTTP fallback, zstd, credential isolation and passive WS status remain available. Other providers retain existing conversion and compatibility paths.

Strict passthrough does not guarantee cross-provider readability. Some official-to-Krill samples succeeded unchanged; Krill-created state may still be rejected by the official upstream. This release preserves the failure and history rather than promising universal lossless switching. Application, installer and updater versions are all `0.1.3`.

Validation: 4,363 Rust regression tests, 68 provider/proxy integration tests, TypeScript, Clippy and release-summary checks passed. Live official/Krill tests with `gpt-6.1-sol` covered prewarm, incremental context, tools, compaction, reasoning and cross-provider rejections. Thirteen existing ignored tests and two Windows symlink-permission exclusions are not counted as passing.
