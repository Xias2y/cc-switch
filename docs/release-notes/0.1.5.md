# CC Switch For Krill 0.1.5

## 中文

- 修复 Krill Fast／Ultrafast 档位说明仍显示英文的问题。发布目录时跟随 CCS 界面语言翻译已知说明，缓存保留原文；档位 ID、请求透传和原生上下文行为不变。
- 补充 Base URL 与“完整 URL”的准确设置：线路裸域名配合关闭“完整 URL”已经实测可用，无需为了 Ultrafast 更换接口或强制 Body 覆盖。
- 更正 Ultrafast 验收说明：HTTP 请求已命中 Krill 的 Ultrafast 路由归类和计费，完成响应仍可能返回 default；这不等于已证明比 Fast 获得额外提速。
- 明确本次 WS 426 来自账号 5 个并发连接名额已满，并非线路不支持 WS。

升级后重新应用当前路由／聚合配置，并完整退出、重启 Codex，使其读取中文说明。语言切换后也需重新应用并重启 Codex。Windows x64 安装包使用原更新密钥签名，支持应用内升级。

本次仅做静态审查、类型检查和发布构建／签名校验；未新增模型调用或运行验收测试。HTTP 路由／计费结论来自升级前完成的独立实测；真实额外加速尚未证实。

## English

- Localize known Krill Fast/Ultrafast descriptions in Codex catalogs according to the CCS UI language while retaining raw cache metadata, tier IDs, request passthrough and native context behavior.
- Clarify Base URL / Full URL setup: the tested line origin works with Full URL off. Ultrafast does not require a different endpoint or a forced Body override.
- Correct the HTTP finding: Krill classified and billed the isolated requests as Ultrafast even though completions reported default. Additional acceleration over Fast remains unverified.
- Identify the observed WS 426 as an account limit of five concurrent sessions, rather than unsupported WebSockets.

After upgrading or changing language, reapply the current routing/aggregation configuration and fully restart Codex to reload descriptions. The Windows x64 installer is signed with the existing updater key and supports in-app updates.

This release received static review, type checking, release build and signature verification only; no new model calls or runtime acceptance tests were run. HTTP classification/billing findings come from the isolated requests completed before this update.
